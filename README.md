# 健身APP - 单车小程序

基于Figma设计一比一复刻的深色主题健身应用，包含完整的运动数据展示、目标设置、实时运动和历史记录功能。

## 项目结构

### TuYa Mini App 版本
位于 `app/` 目录，使用 TuYa 小程序框架开发。

**页面列表：**
- `pages/index/` - 首页（运动数据展示、功能模块）
- `pages/target/` - 目标设置页（距离/时间/卡路里/阻力选择器）
- `pages/exercise/` - 运动实时数据页（仪表盘、控制按钮）
- `pages/history/` - 历史记录页（列表样式、统计图表）
- `pages/history-detail/` - 历史记录详情页
- `pages/congrats/` - 运动完成恭喜页
- `pages/settings/` - 设置页
- `pages/alarm/index/` - 闹钟设置页（日历视图、闹钟管理）
- `pages/ftms/` - FTMS蓝牙设备连接页

**组件列表：**
- `components/bottom-nav/` - 底部导航栏组件


## 设计规范

### 颜色方案（深色主题）

- **主背景**: `#0A0E27`
- **次背景**: `#1A1D35`
- **卡片背景**: 渐变 `#1A1D35` → `#252840`
- **主色调**: `#4A90E2` (蓝色)
- **主文字**: `#FFFFFF`
- **次要文字**: `#8E8E93`
- **成功色**: `#52C41A`
- **错误色**: `#FF4D4F`

### 字体规范

- 大标题: 28px, bold
- 中标题: 20px, bold
- 正文: 16px
- 小字: 14px, 12px

### 间距规范

- 页面内边距: 40px 20px
- 卡片圆角: 16px
- 元素间距: 16px, 12px, 8px
- 按钮高度: 56px

## 功能特性

### 首页 (`pages/index/`)
- ✅ 用户头像和问候语
- ✅ 今日数据卡片（总里程、运动时长、消耗热量）- 动态加载
- ✅ 功能模块网格（目标设置、开始运动、历史记录、设置）
- ✅ 本周统计数据

### 目标设置页 (`pages/target/`)
- ✅ 目标类型选择（距离、时间、卡路里、阻力）
- ✅ 滚动选择器（根据类型动态调整范围和步长）
- ✅ 实时显示当前选择值
- ✅ 开始运动按钮（传递目标参数到运动页）

### 运动实时数据页 (`pages/exercise/`)
- ✅ 实时计时显示
- ✅ 速度仪表盘（圆形仪表）
- ✅ 数据卡片（距离、消耗、心率、阻力值）
- ✅ 阻力调节滑块（1-20级）
- ✅ 暂停/继续按钮
- ✅ 结束按钮（保存数据并跳转恭喜页）

### 历史记录页 (`pages/history/`)
- ✅ 本周运动统计图表（柱状图）
- ✅ 历史记录列表（从本地存储加载）
- ✅ 点击记录查看详情

### 历史记录详情页 (`pages/history-detail/`)
- ✅ 显示单次运动完整数据
- ✅ 包含：时长、卡路里、距离、心率、阻力、平均速度、最大速度

### 运动完成恭喜页 (`pages/congrats/`)
- ✅ 恭喜标题和图标
- ✅ 环形图数据可视化（距离、卡路里、时长完成度）
- ✅ 详细数据展示（平均速度、心率、阻力）
- ✅ 返回首页/查看历史按钮

### 设置页 (`pages/settings/`)
- ✅ 运动提醒功能（每日提醒时间设置）
- ✅ 跳转到闹钟设置页
- ✅ 跳转到FTMS蓝牙设备连接页

### 闹钟设置页 (`pages/alarm/index/`)
- ✅ 日历视图（显示每日闹钟设置状态）
- ✅ 闹钟列表（支持多个闹钟）
- ✅ 闹钟开关（启用/禁用）
- ✅ 闹钟删除功能
- ✅ 自定义重复周期（每天、每周特定日期）

### FTMS蓝牙设备连接页 (`pages/ftms/`)
- ✅ FTMS功能开关
- ✅ 阻力值设置（1-20级）
- ✅ 设备DP点控制（发送指令到TuYa设备）
- ✅ 设备连接状态管理

## 运行说明

### TuYa Mini App 版本

1. 使用 TuYa 开发者工具打开项目
2. 配置 `project.tuya.json`
3. 安装依赖：
```bash
npm install
```
4. 编译运行

## 文件说明

### TuYa Mini App 文件结构
```
app/
├── app.js              # 应用入口
├── app.json            # 应用配置（页面路由）
├── app.tyss            # 全局样式
├── assets/             # 静态资源（图片、图标）
│   ├── icons/          # 图标资源
│   └── *.png, *.svg    # 图片资源
├── components/         # 公共组件
│   └── bottom-nav/     # 底部导航栏组件
├── i18n/               # 国际化
│   └── strings.json    # 多语言字符串
└── pages/              # 页面目录
    ├── index/          # 首页
    ├── target/         # 目标设置页
    ├── exercise/       # 运动实时数据页
    ├── history/        # 历史记录页
    ├── history-detail/ # 历史记录详情页
    ├── congrats/       # 运动完成恭喜页
    ├── settings/       # 设置页
    ├── alarm/          # 闹钟设置页
    │   └── index/
    └── ftms/           # FTMS蓝牙连接页
```

每个页面包含：
- `*.js` - 页面逻辑
- `*.json` - 页面配置
- `*.tyml` - 页面模板
- `*.tyss` - 页面样式

## 注意事项

1. **图片资源**: 图片需要放在 `app/assets/` 目录下
2. **颜色值**: 严格按照设计规范中的颜色值使用
3. **设备连接**: 需要配置 `project.tuya.json` 中的设备ID才能使用DP点功能
4. **本地存储**: 使用 `ty.getStorageSync` 和 `ty.setStorageSync` 进行数据持久化
5. **导航**: 使用 `ty.navigateTo`、`ty.redirectTo`、`ty.navigateBack` 进行页面跳转
6. **交互**: 所有按钮和可交互元素都有适当的反馈效果
