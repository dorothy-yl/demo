# 健身APP - 单车小程序

基于Figma设计一比一复刻的深色主题健身应用，包含完整的运动数据展示、目标设置、实时运动和历史记录功能。

## 项目结构

本项目包含两个版本：

### 1. TuYa Mini App 版本（主项目）
位于 `app/` 目录，使用 TuYa 小程序框架开发。

**页面列表：**
- `pages/index/` - 首页（运动数据展示、功能模块）
- `pages/goal/` - 目标设置页（时间选择器、确认按钮）
- `pages/exercise/` - 运动实时数据页（仪表盘、控制按钮）
- `pages/history/` - 历史记录页（列表样式、统计图表）

### 2. Vue 版本
位于 `vue-version/` 目录，使用 Vue 3 + Vite 开发，可直接在浏览器运行。

## 设计规范

### 颜色方案（深色主题）

- **主背景**: `#0A0E27`
- **次背景**: `#1A1D35`
- **卡片背景**: 渐变 `#1A1D35` → `#252840`
- **主色调**: `#4A90E2` (蓝色)
- **主文字**: `#FFFFFF`
- **次要文字**: `#8E8E93`
- **成功色**: `#52C41A`
- **错误色**: `#FF4D4F`

### 字体规范

- 大标题: 28px, bold
- 中标题: 20px, bold
- 正文: 16px
- 小字: 14px, 12px

### 间距规范

- 页面内边距: 40px 20px
- 卡片圆角: 16px
- 元素间距: 16px, 12px, 8px
- 按钮高度: 56px

## 功能特性

### 首页 (`pages/index/`)
- ✅ 用户头像和问候语
- ✅ 今日数据卡片（总里程、运动时长、消耗热量）- 动态加载
- ✅ 功能模块网格（目标设置、开始运动、历史记录、设置）
- ✅ 本周统计数据

### 目标设置页 (`pages/goal/`)
- ✅ 目标类型选择（距离、时间、卡路里）
- ✅ 时间选择器（今天、明天、本周、本月）
- ✅ 目标值输入
- ✅ 确认按钮并保存到本地存储

### 运动实时数据页 (`pages/exercise/`)
- ✅ 实时计时显示
- ✅ 速度仪表盘（圆形仪表）
- ✅ 数据卡片（距离、消耗、心率、阻力值）
- ✅ 阻力调节滑块（1-20级）
- ✅ 暂停/继续按钮
- ✅ 结束按钮（保存数据并跳转恭喜页）

### 历史记录页 (`pages/history/`)
- ✅ 本周运动统计图表（柱状图）
- ✅ 历史记录列表（从本地存储加载）
- ✅ 点击记录查看详情

### 历史记录详情页 (`pages/history-detail/`)
- ✅ 显示单次运动完整数据
- ✅ 包含：时长、卡路里、距离、心率、阻力、平均速度、最大速度

### 运动完成恭喜页 (`pages/congrats/`)
- ✅ 恭喜标题和图标
- ✅ 环形图数据可视化（距离、卡路里、时长完成度）
- ✅ 详细数据展示（平均速度、心率、阻力）
- ✅ 返回首页/查看历史按钮

### 设置页 (`pages/settings/`)
- ✅ 运动提醒功能（每日提醒时间设置）
- ✅ 闹钟功能（支持多个闹钟，自定义重复周期）
- ✅ FTMS蓝牙设备连接（扫描和连接健身器材）

## 运行说明

### TuYa Mini App 版本

1. 使用 TuYa 开发者工具打开项目
2. 配置 `project.tuya.json`
3. 编译运行

### Vue 版本

```bash
cd vue-version
npm install
npm run dev
```

访问 `http://localhost:3000`

4. **交互**: 所有按钮和可交互元素都有适当的反馈效果
