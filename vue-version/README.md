# 健身APP - Vue版本

基于Figma设计复刻的深色主题健身应用，包含完整的运动数据展示、目标设置、实时运动和历史记录功能。

## 功能特性

- 🏠 **首页**: 运动数据展示、功能模块布局、本周统计
- 🎯 **目标设置**: 目标类型选择、时间选择器、确认按钮
- 🚴 **运动实时数据**: 仪表盘显示、实时数据更新、控制按钮
- 📊 **历史记录**: 列表样式、统计图表、运动记录详情

## 技术栈

- Vue 3
- Vue Router 4
- Vite

## 安装和运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 设计规范

### 颜色方案（深色主题）

- 背景色: `#0A0E27` (主背景), `#1A1D35` (次背景)
- 卡片背景: `#1A1D35` → `#252840` (渐变)
- 主色调: `#4A90E2` (蓝色)
- 文字颜色: `#FFFFFF` (主文字), `#8E8E93` (次要文字)

### 字体

- 系统默认字体栈
- 标题: 28px, 20px
- 正文: 16px, 14px

### 间距

- 页面内边距: 40px 20px
- 卡片间距: 16px
- 元素间距: 12px, 8px

## 页面结构

```
src/
├── views/
│   ├── Home.vue      # 首页
│   ├── Goal.vue       # 目标设置
│   ├── Exercise.vue   # 运动实时数据
│   └── History.vue     # 历史记录
├── router/
│   └── index.js       # 路由配置
├── App.vue
└── main.js
```

## 注意事项

- 图片资源需要放在 `public/src/image/` 目录下
- 所有颜色值严格按照设计规范使用
- 响应式设计，适配移动端和桌面端
